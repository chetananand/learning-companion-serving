# Runbook: Gate G0 on node 2 (2 x A6000)

The approval in advance allows 8 hours for each block and 16 hours in total, at 2.18 USD/h. Node 2 never runs overnight: no launch after 20:00 PDT, and the spend guard terminates it at 23:00 PDT. This runbook takes about 3 hours 20 minutes (about 7.30 USD). Thus, start it by 19:30 PDT at the latest.

## Before the launch (no cost)

These checks passed on 2026-09-27:

1. Every chart version, manifest URL, and image tag exists. The router chart tag is `v0.11.0`.
2. The HF token reads every model of the plan.
3. `helm` is not on the laptop. Thus the platform install runs on node 2, and the runbook installs `helm` there.
4. `make check` passes, and the spend guard runs.
